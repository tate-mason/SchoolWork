# Problem Set 3 - Econometrics 2

## Purpose
The purpose of this folder is to provide answers to both problems asked in the third problem set. These problems concern a multinomial logit/nested logit and then a multinomial probit.

## Folder Structure
Each subfolder has a unique purpose:

  - `/Problem1` contains the main file `Problem1.py` as well as helper files for each part a-f. Further, there is the provided `dataHW3_Problem1.mat` dataset to be used. Each file will contain a blurb describing general format, libraries called, functions defined, etc.
  - `/Problem2` is the same as problem 1, only there is just a `Problem2.py` and `Problem2a.py` enclosed, along with the data `dataHW3_Problem2.mat`. Each file will be structured as described above.
  - `/Writeup` contains the files used for LaTeX compilation. The writeup itself will be in the main folder `PS3` for easier access.

## Required Software

User will need a Python kernel and IDE along with access to the following libraries:

```python
pandas
numpy
scipy
```

If these libraries are not already installed, they can be via:

```python
pip install pandas
```
